# E000 — generic getarch error

The catch-all base code. You should not normally see this directly: a
working install raises one of the more specific subclass codes
(`E1xx` for config, `E2xx` for environment, `E3xx` for planning,
`E4xx` for execution).

If you do see this code, the install hit an unexpected internal state.
Re-run with `--debug` to capture a full traceback and file a bug at
<https://github.com/fabifont/getarch/issues>.
