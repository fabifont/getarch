# E200 — runtime environment cannot satisfy the install

The host is missing tools, capabilities, or runtime state needed by
the planned install. Common cases:

* `arch-chroot`, `pacstrap`, `cryptsetup`, `sgdisk`, or `mkinitcpio`
  not on `PATH`. The runtime preflight requires the live Arch ISO (or
  an equivalent toolset).
* The user declined a destructive confirmation prompt.
* A wifi/wired bootstrap could not bring up the network (no NIC, no
  signal, wrong PSK).

The error message names the missing tool or step. If you're sure the
host is fine, `--skip-runtime-preflight` can bypass the keyring
refresh, but anything else needs the tool actually installed.
