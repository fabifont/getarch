# E300 — install plan could not be built

The planner refused to assemble a plan from the validated config.
Common causes:

* The target disk in `cfg.disk.path` is not present (or `lsblk` does
  not list it).
* `--resume` was requested but the saved fingerprint disagrees with
  the rendered plan (use `--force-fingerprint` to override).
* `--resume` requested but no state file at `<mount>/var/log/getarch.state.json`.
* A pre-existing pipeline state file was found and `--resume` was not
  passed (refuse-by-default safety guard).

The message names the specific reason. For fingerprint mismatches,
check whether the config or the planner code changed since the
previous run; for missing disks, recheck the path with
`getarch discover --no-cache`.
