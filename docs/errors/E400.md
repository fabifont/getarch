# E400 — a command exited non-zero

A subprocess inside the install pipeline returned a non-zero exit
code. The error message includes:

* the full argv (with `--sensitive` payloads redacted),
* the exit code,
* the tail of the captured stderr.

Re-run with `--debug` to dump the audit log under
`<mount>/var/log/getarch.log` after failure (the install command
flushes it on the failure path automatically).

If the failure is in `pacstrap` / `pacman -Sy`, check that the
`mirrors` step picked a reachable mirror — you can re-run
`getarch discover --no-cache` to refresh the cached lsblk view, then
edit `cfg.mirrors.strategy` accordingly.
