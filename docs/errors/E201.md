# E201 — system discovery failed

`lsblk`, `localectl`, `timedatectl`, or `hostnamectl` returned an
unexpected payload. Usually one of:

* the binary is missing,
* output is not the expected JSON shape (an Arch update changed the
  schema),
* the host is not Linux.

`getarch discover --no-cache` re-runs the underlying commands without
the discovery cache so you can see the raw stderr.
