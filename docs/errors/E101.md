# E101 — config cannot be parsed

The file at the configured path either:

* does not exist,
* is not readable, or
* fails to parse against the version 1 (or 2) schema (e.g. an unknown
  field, a wrong type, a missing required field).

What to try:

1. Run `getarch validate <path>` for a focused parser-only error.
2. Compare your file against `getarch examples minimal-ext4` for the
   minimal valid shape.
3. If the parser complaint is from pydantic, the location it reports
   (`location: ('disk', 'path')`) maps to the JSON/YAML/TOML key path.
